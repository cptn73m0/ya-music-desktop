# YaMusic Desktop Client

Нативная обёртка над веб-версией **Яндекс Музыки** (`music.yandex.ru`) на Python + pywebview.

## Ключевые фичи

- **Веб-интерфейс ЯМ** в нативном окне с мостом `JS <-> Python`.
- **Кнопки «Скачать» ⬇** прямо в списке треков, на страницах альбомов и плейлистов —
  рядом с нужным объектом.
- **Блокировщик рекламы** (CSS + перехват `fetch`/`XHR`/`window.open`) и
  **автопринятие cookie / GDPR**-баннеров.
- **Токен в защищённом хранилище** (`keyring`); если токен не задан — открывается
  модальное окно с инструкцией и ссылкой на получение токена.
- **Скачивание через `yandex-music`**: трек, альбом, плейлист.
  Файлы сохраняются с **ID3-тегами** и **обложкой**.
- **Настройка структуры загрузок**: один каталог / по исполнителям / по альбомам
  (объединение треков одного альбома в одну папку) / `Исполнитель → Альбом`.

## Запуск

```bash
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py
```

Только что скачанный токен сохраняется в системном хранилище ключей,
повторно вводить не нужно.

## Сборка в exe (будущая задача)

```bash
venv\Scripts\pyinstaller --onefile --windowed --add-data "assets:assets" main.py
```

## Безопасность

- Токен хранится в `keyring` (Windows Credential Manager и т.п.) и **никогда**
  не выводится в консоль в открытом виде.
- Настройки локальны: `~/.ya-music-desktop/settings.json`.
