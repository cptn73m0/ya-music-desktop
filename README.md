# YaMusic Desktop Client

Десктопная обёртка над веб-версией Яндекс Музыки с возможностью скачивать треки, альбомы и плейлисты прямо из интерфейса.

**English version: [README_EN.md](README_EN.md)**

## Что умеет

- Открывает music.yandex.ru в отдельном окне (pywebview + Edge WebView2).
- Добавляет кнопки скачивания рядом с треками, альбомами и на страницах плейлистов.
- Скачивает музыку через библиотеку `yandex-music` в формате MP3 (320/192/128 kbps, если 320 недоступен — берёт ниже).
- Проставляет ID3-теги и встраивает обложку (mutagen).
- Блокирует рекламные запросы и баннеры, автоматически принимает cookie-баннеры.
- Настройка структуры каталогов: всё в одну папку, по исполнителям, по альбомам, исполнитель/альбом.
- Сохраняет сессию Яндекса между запусками — повторная авторизация не нужна.
- Показывает прогресс скачивания плейлиста в отдельном тосте.

## Установка и запуск из исходников

Требуется Python 3.9+ (Windows 10/11).

```
git clone https://github.com/cptn73m0/ya-music-desktop.git
cd ya-music-desktop
python -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python main.py
```

## Готовая сборка

В папке `dist` лежит портативный `YaMusicDesktop.exe` — не требует установки, работает сразу. Для отображения страницы нужен Edge WebView2 Runtime (на Windows 10/11 он обычно уже стоит).

Пересобрать самому:

```
tools\build.ps1
```

Скрипт поставит PyInstaller, сгенерирует иконку (`tools\make_icon.py`) и соберёт один exe в `dist\`.

## Токен для скачивания

При первом скачивании приложение попросит OAuth-токен Яндекс Музыки:

1. Перейдите по ссылке из окна (или `ym.marshal.dev`) и получите токен.
2. После редиректа скопируйте значение `access_token` из адресной строки.
3. Вставьте в поле и сохраните.

Токен хранится в системном менеджере паролей (Windows Credential Manager) через `keyring`. В логи и консоль не пишется.

## Структура проекта

- `main.py` — точка входа, создание окна, мост JS-Python.
- `core/auth.py` — хранение и проверка токена.
- `core/downloader.py` — скачивание треков/альбомов/плейлистов, теги, обложки.
- `core/settings.py` — путь загрузок и структура каталогов (`~/.ya-music-desktop/settings.json`).
- `assets/inject.js` — кнопки скачивания в DOM ЯМ, блокировщик рекламы, тосты, модалки.
- `tools/` — генерация иконки и сборка exe.

## Известные ограничения

- Селекторы Яндекс Музыки периодически меняются; кнопки могут пропасть после обновления вёрстки — в этом случае заведите issue.
- Редакционные плейлисты с UUID-ссылками резолвятся через `GET /playlist/<uuid>`.
- Треки, недоступные в вашем регионе, пропускаются и попадают в список ошибок.
